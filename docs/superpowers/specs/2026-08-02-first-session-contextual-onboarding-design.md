# [대체됨] First-Session Contextual Onboarding Design

상태: `[대체됨 · 역사 증거]`

이 문서는 실제 첫 무한 run에서 LOAD·분기·LIFO·Combo·저연료 BOOST를 가르치는 old product onboarding spec이었다.

`GMB-002 · SX-DEC-034`에 따라 현재 제품은 다음 구조를 사용한다.

- 1~10 수작업 튜토리얼
- 한 스테이지당 새 핵심 개념 1개
- 실패 허용과 원인 시각화
- 요청형 3단계 힌트
- 10스테이지 종합 시험 뒤 본편·랭킹 개방
