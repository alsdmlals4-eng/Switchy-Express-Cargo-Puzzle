# [폐기] Difficulty Escalation Communication Design

상태: `[폐기 · 역사 증거]`

이 문서는 무한 생존 run에서 시간 경과 speed·fuel pressure를 전달하는 old product spec이었다.

`GMB-002 · SX-DEC-027/029`에 따라 다음 제품 규칙은 폐기됐다.

- 연료 소모·회복·fuel-zero 종료
- 시간 경과 speed/fuel pressure escalation
- BOOST panic input

새 제품의 난도는 수작업 맵의 화물·역·건설 불가 지형·제한 시간·별 목표·선로 비용으로 구성한다.

- `기획서/20_시스템_콘텐츠/CORE_SYSTEMS.md`
