## Phase 1 design review

- **Core fun to experience:** connected. A player sees route placement, then pays for the choice through later TOP/service/switch consequences.
- **What the player judges:** reachable route and cardinal service in BUILD; current TOP/load mode/branch lock in RUN; one cause/recovery action at result.
- **Immediate outcome:** implemented semantic overlays and causal result copy are present. Actual human immediacy remains unverified.
- **Failure learning:** designed as Retry same layout vs Edit. Whether players choose correctly needs Phase 5 evidence.
- **First-session sale point:** T2/T3/T6 collectively show the unusual route→stack→execution link. A single title screenshot cannot prove it.
- **Scope:** A is bounded to existing consumers. Image batch, new systems, and #227 are excluded.
- **Reuse:** project presentation owners are reused; Base RM-VIS profile is rejected now because its declared destinations do not exist.
