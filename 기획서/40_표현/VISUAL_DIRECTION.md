# Visual Direction

## Visual Pillars

1. **Cute premium casual** — 둥글고 부드러운 3D 카툰, 따뜻한 조명, 친근한 표정
2. **Toy railway clarity** — 장난감 철도판처럼 선로·침목·곡선·분기 구조가 즉시 읽힘
3. **Global readability** — 짧은 텍스트, 명확한 아이콘, 색상+모양 이중 부호
4. **Juicy logistics** — 적재 결합, 스위치 전환, LIFO 하역 Combo, 부스터에 강한 즉시 피드백
5. **Cozy mascot world** — 토끼 기관사와 작은 역·초원·꽃·물가·미니어처 소품

## 화면 구성

### 상단 HUD
- 점수
- 연료 게이지
- 현재 속도
- 이번 run 최대 Combo
- 생존 시간
- 일시정지

### 중앙 맵
- 가로형 15×10
- 레일은 배경보다 높은 명암 대비
- 현재 활성 경로는 굵은 발광선과 화살표
- 비활성 후보 경로는 어둡게
- 분기 레버와 단계 상태 표시
- 역은 색상+별/마름모/삼각형
- 화물은 같은 색·모양 체계

### 하단 HUD
- 왼쪽 `LOAD`
- 중앙 `UNLOAD ORDER`: 맨 왼쪽이 다음 하역 화물
- 오른쪽 `BOOST`

## Combo 피드백 — SX-DEC-014

- 성공 하역 직후 역·열차 인접 위치에 `COMBO ×N`을 표시한다.
- `N`은 이번 한 번의 역 도착에서 연속 하역된 동일 cargo_type 개수다.
- 여러 배송을 잇는 streak 게이지·타이머는 표시하지 않는다.
- 상단 HUD의 Combo 값은 이번 run의 `max_combo`를 안정적으로 표시한다.
- 결과 화면은 `MAX COMBO`와 신기록 여부를 표시한다.
- 빠른 배송의 `speed_bonus`가 발동하면 Combo와 분리된 작은 속도 보너스 피드백을 사용한다.
- 피드백 지속 시간·크기·이징은 `TEST_VALUE`이며 Reduced Motion에서는 즉시 정적 표기로 대체한다.

## 분기기 UX

- 2단계 분기기는 두 후보를 동시에 볼 수 있어야 함
- 3단계 분기기는 단계 수와 현재 단계 표시
- 직진 가능한 분기에서는 직진 방향을 기본 A노선으로 표현
- 탭 즉시 활성 레일이 바뀜
- 선택 경로 3~5칸에 방향 화살표
- 실제 진행 방향과 UI 미리보기가 다르면 P0 결함
- 분기 통과 뒤 기본 A노선 복귀가 레버·레일 강조에 즉시 반영
- 직진 A노선과 회전 B/C노선은 굵기·발광·화살표를 함께 사용해 구분

현재 PR #9는 분기 상태·직진 우선·5칸 경로 데이터만 검증했다. 실제 선로·레버·화살표 화면과 터치 영역은 아직 구현·검증되지 않았다.

## 접근성

- 빨강=별, 파랑=마름모, 노랑=삼각형
- 색상만으로 하역 가능 여부를 전달하지 않음
- 활성 선로는 색+굵기+화살표를 함께 사용
- 버튼은 48dp 이상 터치 영역
- 중요한 점수·연료 정보는 높은 명암 대비 유지
- 3단계 분기 상태는 색뿐 아니라 단계 점·번호·레버 방향 중 둘 이상으로 표시
- Combo는 숫자와 `COMBO` 텍스트를 함께 표시하고 색·모션만으로 전달하지 않음

## 오디오·햅틱 권장 계약

분류: `RECOMMENDED_DEFAULT`.

| 우선순위 | 사건 | 기본 피드백 | mute·haptic-off 대체 |
|---:|---|---|---|
| P0 | 연료 위험·게임오버 | 경고음·짧은 위험 진동 | 게이지 점멸·위험 아이콘·정적 결과 원인 |
| P1 | 분기 전환 접수·목표 잠금 | 레버 클릭·짧은 탭 진동 | 레버 상태·활성 경로 즉시 변경 |
| P1 | 화물 적재·하역 Combo | 결합음·하역 상승음·단계 진동 | stack/HUD 즉시 갱신·`COMBO ×N` |
| P2 | BOOST 시작·종료 | 엔진 피치 변화·지속 약진동 | BOOST 버튼·속도·연료 배율 표시 |
| P2 | speed bonus | 짧은 성공음 | 별도 보너스 배지·점수 증가 분리 표시 |

- 소리·진동은 입력 접수와 도메인 결과를 구분한다.
- 오디오·햅틱 완료는 점수·연료·분기·적재·저장의 권위가 아니다.
- P0/P1 정보는 mute·haptic-off에서도 시각적으로 완전해야 한다.
- 구체 파형·볼륨·진동 길이는 제품 테스트 전 `TEST_VALUE`다.

## 승인된 시각 참고

사용자가 승인한 생성 콘셉트는 방향 참고이며 실제 게임 캡처·최종 자산이 아니다. 저장소 자산 원본 등록 전 상태는 `APPROVED_REFERENCE_PENDING_ASSET_IMPORT`다.

## UI 모션·중단·반복 계약

```text
입력 접수 → 처리 중 → 도메인 결과 확정 → 결과 표현
```

- 분기 전환·LOAD·화물 적재·LIFO 하역·Combo·BOOST·결과·재시작 모션은 중단과 즉시 완료 경로를 가진다.
- 빠른 반복·재진입·재시작에서 분기 상태·화물 stack·점수·연료·배송·spawn이 중복되지 않아야 한다.
- `AnimationPlayer`·`Tween` 완료 signal은 선로 선택·적재·하역·점수·연료·게임오버·저장의 권위 시점이 아니다.
- `Reduced Motion`, `mute`, `haptic-off`에서도 활성 경로·다음 하역·연료·위험·결과 원인·다음 행동을 보존한다.
- Android safe area·48dp·성능·사람 이해는 `NOT_RUN` / `HUMAN_NOT_RUN`으로 유지한다.
