# Visual Direction

## Visual Pillars

1. **Cute premium casual** — 둥글고 부드러운 3D 카툰, 따뜻한 조명, 친근한 표정
2. **Toy railway clarity** — 장난감 철도판처럼 선로·침목·곡선·분기 구조가 즉시 읽힘
3. **Global readability** — 짧은 텍스트, 명확한 아이콘, 색상+모양 이중 부호
4. **Juicy logistics** — 적재 결합, 스위치 전환, 하역 콤보, 부스터에 강한 즉시 피드백
5. **Cozy mascot world** — 토끼 기관사와 작은 역·초원·꽃·물가·미니어처 소품

## 화면 구성

### 상단 HUD
- 점수
- 연료 게이지
- 현재 속도
- 콤보
- 생존 시간
- 일시정지

### 중앙 맵
- 가로형 15×10
- 레일은 배경보다 높은 명암 대비
- 현재 활성 경로는 굵은 발광선과 화살표
- 비활성 후보 경로는 어둡게
- 분기 레버와 단계 상태 표시
- 역은 색상+별/마름모/삼각형
- 화물은 같은 색·모양 체계

### 하단 HUD
- 왼쪽 `LOAD`
- 중앙 `UNLOAD ORDER`: 맨 왼쪽이 다음 하역 화물
- 오른쪽 `BOOST`

## 분기기 UX

- 2단계 분기기는 두 후보를 동시에 볼 수 있어야 함
- 3단계 분기기는 단계 수와 현재 단계 표시
- 분기 탭 즉시 활성 레일이 바뀜
- 선택 경로 3~5칸에 방향 화살표
- 실제 진행 방향과 UI 미리보기가 다르면 P0 결함

## 접근성

- 빨강=별, 파랑=마름모, 노랑=삼각형
- 색상만으로 하역 가능 여부를 전달하지 않음
- 활성 선로는 색+굵기+화살표를 함께 사용
- 버튼은 48dp 이상 터치 영역
- 중요한 점수·연료 정보는 높은 명암 대비 유지

## 승인된 시각 참고

사용자가 승인한 생성 콘셉트는 방향 참고이며 실제 게임 캡처·최종 자산이 아니다. 저장소 자산 원본 등록 전 상태는 `APPROVED_REFERENCE_PENDING_ASSET_IMPORT`다.
