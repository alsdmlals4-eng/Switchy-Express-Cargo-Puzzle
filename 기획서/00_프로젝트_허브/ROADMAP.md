# Roadmap

## M0 — 운영체계 설치

- GitHub 정본·Registry·Base Adapter·Google Sheets GDD 연결
- 새 작업자가 저장소만으로 현재 결정과 다음 작업 복원
- 설치 검증 보고

## M1 — Vertical Slice 기반

- Godot 4.7.1 프로젝트와 헤드리스 테스트 러너
- 15×10 연결 철도망
- 2단계·3단계 분기기
- 기차 이동·화차 추종

종료 기준: 같은 시드에서 결정론적 생성, 전체 연결, 막다른길 0, 분기 선택과 실제 경로 일치.

## M2 — 핵심 생존 루프

- 홀드 적재
- 색상별 최소 화물 유지
- LIFO 하역
- 점수·연료·속도·화물 감속·부스터
- 게임오버·재시작

종료 기준: 무조작 영구 생존 불가, 같은 색 연속 하역, 숙련 입력이 생존과 점수를 개선.

## M3 — 목표 품질 Vertical Slice

- 모바일 가로형 HUD
- 귀엽고 친근한 프리미엄 캐주얼 시각 방향
- 접근성 모양 표식
- 효과음·진동·주요 피드백
- 대표 플레이 캡처

## M4 — 플레이테스트·Production Gate

- 행동 로그와 플레이테스트 기록
- 밸런스 재조정
- MUST_FIX 회귀 검증
- Production 진입 판단
