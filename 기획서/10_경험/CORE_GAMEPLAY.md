# Core Gameplay

## 플레이어 약속

> 필요한 화물을 고르고, 분기기를 미리 바꾸고, 마지막에 실은 화물부터 같은 색 역에 연속 하역해 연료와 점수를 이어간다.

## 핵심 루프

```text
자동 운행
→ 화물 접근
→ LOAD를 누르는 동안 선택 적재
→ 분기기 상태 확인·전환
→ 스테이션 도착
→ LIFO 연속 하역
→ 점수·연료 회복
→ 시간 경과로 속도·연료 압박 증가
→ BOOST로 이동 시간과 연료를 교환
→ 연료 0에서 결과
```

## 조작

| 입력 | 행동 |
|---|---|
| `LOAD` 홀드 | 지나가는 화물을 적재 |
| 분기기 탭 | 해당 분기기의 다음 활성 노선으로 순환 |
| `BOOST` 홀드 | 현재 속도를 높이고 연료를 추가 소비 |
| 일시정지 | 운행과 입력 정지 |

`LOAD`와 `BOOST`가 동시에 입력되면 `BOOST`를 우선하고 적재를 비활성화한다.

## 맵 경험

- 가로형 15×10 격자
- 모든 선로가 하나의 네트워크로 연결
- 막다른길 없음
- 최소 3개의 의미 있는 순환 경로
- 분기 후 경로가 최소 3칸 이상 다르게 이어지는 실제 선택
- 한 판 중 맵은 고정되어 학습과 숙련이 가능
- 새 판 시작 시 검증된 생성 규칙 안에서 노선·역·화물 배치를 변경

## 분기기

- 2단계 분기기: `A → B → A`
- 3단계 분기기: `A → B → C → A`
- 미입력 시 현재 기본 선로 유지
- 통과 후 기본 상태 복귀
- 현재 활성 선로를 굵은 색·방향 화살표로 표시
- 탭 시 선택 경로 3~5칸을 즉시 강조
- 가장 가까운 역의 색·모양 표식을 보조 표시

## LIFO 하역

적재 순서 `빨강 → 빨강 → 파랑 → 빨강`은 하역 순서 `빨강 → 파랑 → 빨강 → 빨강`이 된다.

현재 역 색상과 하역 맨 앞 화물이 같을 때만 하역한다. 다음 화물 색이 달라지는 순간 하역을 중단한다.

## 플레이어 고민

1. 현재 보이는 화물을 실어도 원하는 하역 스택이 만들어지는가
2. 지금 분기기를 바꾸면 어느 역과 화물 구간으로 이어지는가
3. 더 싣고 큰 콤보를 노릴지 빠르게 하역할지
4. 무거워진 기차를 부스터로 보완할지 연료를 보존할지
5. 안전 생존과 시간당 점수 중 무엇을 우선할지

## 게임오버

주 게임오버 조건은 연료 0이다. 잘못된 분기·화물 적재는 즉시 종료가 아니라 점수·연료 효율 악화로 이어진다.
